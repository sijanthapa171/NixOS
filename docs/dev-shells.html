Dev Shell Templates

Instant, reproducible development environments for nearly every language. Powered by Nix flakes — nix develop or auto-activated by direnv.

How to use

01

Create a new project

bash
$ nix flake new -t ~/NixOS#rust myproject
02

Enter the dev shell

bash
$ cd myproject && nix develop
03

Or use the shell aliases

bash
$ fnew rust myproject   # new dir
$ finit python          # init in cwd
💡
With direnv (included in this config), the shell activates automatically when you enter the project directory. fnew and finit run direnv allow for you.

All templates use https://flakehub.com/f/NixOS/nixpkgs/0.1 (unstable nixpkgs) and support x86_64-linux · aarch64-linux · x86_64-darwin · aarch64-darwin.

direnv — Zero-friction shell activation

Every template ships with a pre-configured .envrc. Once allowed, the shell activates automatically on cd.

bash
# one-time allow per project
$ nix flake new -t ~/NixOS#python myproject
$ cd myproject
$ direnv allow

# every subsequent entry auto-activates
$ cd myproject
direnv: loading .envrc
direnv: using flake
✓ Python 3.13 · .venv created · pip ready
ℹ
fnew <template> <dir> creates the project and runs direnv allow in a single command. finit <template> does the same in the current directory.
