One-Variable Config

Every option in variables.nix maps to a module loaded at eval time. Change desktop, editor, videoDriver, or theme — rebuild once.

See variables →

Multi-Host Support

Manage multiple machines from one flake. The installer creates a new host by copying a template, patching it, and adding it to flake.nix automatically.

Manage hosts →

One-Command Install

Both install.sh (running system) and live-install.sh (ISO) handle partitioning, encryption, GPU selection, hardware config, and nixos-install.

Installation guide →

Instant Rollbacks

Every generation is preserved. The built-in rollback N script or the GRUB boot menu lets you revert in seconds.

Hyprland

Lua-based, bleeding-edge Wayland.

Hyprland is configured in pure Lua — not .conf. Variables from variables.nix are baked into a variables.lua at build time.

~/.config/hypr/settings.lua
-- general
hl.config({ general = { gaps_in = 4, gaps_out = 9, border_size = 2,
  col = { active_border = { colors = { "rgba(ca9ee6ff)", "rgba(f2d5cfff)" } } },
  layout = "dwindle", resize_on_border = true },
  decoration = { rounding = 10, blur = { enabled = true, size = 6 } } })
