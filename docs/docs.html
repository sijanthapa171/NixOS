Documentation

Complete guide for installing, configuring, and managing this NixOS flake configuration.

Prerequisites

  • A machine running NixOS, or the NixOS minimal live ISO
  • Git — use nix-shell -p git on the live ISO if needed
  • Internet connection for fetching flake inputs
ℹ
NixOS only. install.sh checks for NixOS via /etc/os-release and exits on any other distro.

Install — Running NixOS System

bash
$ git clone https://github.com/sijanthapa171/NixOS.git ~/NixOS
$ cd ~/NixOS
$ ./install.sh

The interactive installer will:

  1. Show existing hosts or let you create a new one (with template copy)
  2. Prompt GPU driver selection — nvidia / amdgpu / intel
  3. Patch username in variables.nix to the current user
  4. Open variables.nix for final customization
  5. Copy or generate hardware-configuration.nix
  6. Run nixos-rebuild boot --flake .#<HOST>
💡
After a successful build, reboot to apply the new configuration.

Install — Live ISO

Download the NixOS Minimal ISO, boot it, connect to the internet, then:

bash
$ nix-shell -p git
$ git clone https://github.com/sijanthapa171/NixOS.git ~/NixOS
$ cd ~/NixOS && ./install.sh

install.sh detects the live environment and launches live-install.sh, which handles full interactive disk setup:

  • Host selection and creation
  • Username + password setup
  • GPU driver selection
  • Partitioning: automatic (512 MB EFI + configurable swap + root) or manual (cfdisk)
  • Filesystem choice: ext4 or btrfs
  • Optional LUKS encryption for root and home partitions
  • Hardware config generation, nixos-install, user directories, ownership
⚠
Caution: The live installer will format disks. Back up data before proceeding.

variables.nix — The Control Center

The single source of truth for all per-host preferences. Every value here is imported at Nix eval time and used to select modules dynamically.

nix
{
  username = "yourname";          # set automatically by install.sh

  # Desktop Environment
  desktop = "hyprland";           # hyprland | gnome | plasma6 | i3

  # Theme & Appearance
  bar = "noctalia";              # waybar | hyprpanel | noctalia | wayle | caelestia
  waybarTheme = "minimal";       # stylish | minimal  (waybar only)
  sddmTheme = "astronaut";       # astronaut | black_hole | purple_leaves
                                  #   jake_the_dog | hyprland_kath
  defaultWallpaper = "galaxy.webp";
  hyprlockWallpaper = "galaxy.webp";

  # Default Applications
  terminal = "kitty";            # kitty | alacritty | wezterm
  editor = "nixvim";             # nixvim | vscode | helix | doom-emacs | nvchad | neovim
  browser = "firefox";           # firefox | zen-beta | floorp
  fileManager = "thunar";        # yazi | lf | thunar
  shell = "zsh";                 # zsh | bash
  games = false;                 # true | false  → toggles entire gaming module

  # Hardware
  hostname = "NixOS";
  videoDriver = "intel";         # nvidia | amdgpu | intel
  nvidiaChannel = "stable";      # stable | latest | beta | legacy_xxx  (nvidia only)
  bluetoothSupport = true;
  batterySupport = true;

  # Localization
  timezone = "Asia/Kathmandu";
  locale = "en_US.UTF-8";
  clock24h = true;
  kbdLayout = "us";
  kbdVariant = "";
  consoleKeymap = "us";
  capslockAsESC = false;        # swap Capslock ↔ Escape (udev + XKB)
}
⚠
After editing variables.nix, run rebuild or press Super+U for changes to take effect.

host-packages.nix

Machine-specific packages go here. The Default laptop host includes, for example:

nix
{ pkgs, ... }: {
  environment.systemPackages = with pkgs; [
    obsidian          # notes
    godot             # game development
    ludusavi          # game save backups
    proton-vpn        # VPN client
    github-desktop
    vscode
    kiro              # AI IDE
    brave
    telegram-desktop
    google-chrome
    (retroarch.withCores (cores: with cores; [
      dolphin mgba melonds pcsx2 ppsspp snes9x
      mupen64plus swanstation mame flycast # …and more
    ]))
  ];
}

The vega (WSL) host includes Java 21, Maven, glib/gtk3/Mesa, Node.js, pnpm, and bun.

configuration.nix

Entry point per host. Module selection is entirely driven by variables.nix via string interpolation in import paths and lib.optional:

nix
# Dynamic module paths from variables
../../modules/desktop/${vars.desktop}
../../modules/programs/browser/${vars.browser}
../../modules/programs/terminal/${vars.terminal}
../../modules/programs/editor/${vars.editor}
../../modules/programs/file-manager/${vars.fileManager}
../../modules/hardware/video/${vars.videoDriver}.nix

# Boolean-conditional module
++ lib.optional (vars.games == true) ../../modules/core/games.nix

New Host — Automatic

Run the installer and type n when prompted to create a new host:

bash
$ cd ~/NixOS && ./install.sh

The script: enters the new host name → selects a template → cp -r hosts/<template> hosts/<new> → patches hostname in variables.nix → appends the host to flake.nix → builds.

New Host — Manual

bash
$ cp -r hosts/Default hosts/Laptop
$ nano hosts/Laptop/variables.nix

Add the host to flake.nix:

nix
nixosConfigurations = {
  Default = mkHost "Default";
  vega    = mkHost "vega";
  Laptop  = mkHost "Laptop";  # ← new
};
bash
$ sudo nixos-rebuild switch --flake ~/NixOS#Laptop

Rollbacks

bash
# list all system generations
$ list-gens

# roll back to generation N (uses nh if available, else direct switch)
$ rollback N
💡
You can also select a previous generation from the GRUB boot menu — no commands needed.

Updating Flake Inputs

bash
# update all inputs AND rebuild in one shot
$ sysup

# or individually
$ nix flake update --flake ~/NixOS
$ rebuild

nh handles garbage collection automatically — it keeps the last 3 generations and anything from the past 7 days.

Desktop Environments

Set desktop in variables.nix. Located at modules/desktop/.

Hyprland

Uses the upstream Hyprland flake. Config in pure Lua — 6 files. Variables baked in at build time via Nix string interpolation.

  • Bar: waybar · noctalia · hyprpanel · wayle · caelestia
  • Companions: rofi · wlogout · hypridle · hyprlock · swaync · hyprpolkitagent
  • Layout: dwindle · master · scrolling · monocle
  • VRR (fullscreen-only), window swallowing (kitty/alacritty), cliphist, awww wallpaper
  • 20+ Hyprland-specific scripts in modules/desktop/hyprland/scripts/

GNOME

Bloat removed, Catppuccin applied, quality-of-life extensions included.

  • Includes: gnome-tweaks, Vitals extension, ArcMenu
  • Excludes: maps, music, tour, text-editor, contacts, gedit, epiphany, cheese
  • TLP disabled (GNOME handles power management itself)

KDE Plasma 6

Fully declarative via plasma-manager. Catppuccin Mocha Mauve global theme.

  • 5 virtual desktops, cube effect, NixOS snowflake kickoff icon
  • Custom panel: pager · kickoff · icon tasks · system tray · clock
  • PowerDevil AC/battery profiles, charge thresholds, lid-close behavior
  • Baloo indexer disabled, kscreenlocker configured

i3

Classic tiling WM with Polybar, Dunst, Picom compositing, and Rofi.

  • Catppuccin-colored borders, inner/outer gaps = 4
  • 10 workspaces mapped to DP-0, HDMI-0, HDMI-1
  • Feh for wallpaper, Cava audio visualizer, xrandr

Hardware Modules

GPU Drivers — modules/hardware/video/

Set via videoDriver in variables.nix:

nvidia amdgpu intel

The NVIDIA module sets full Wayland env vars (GBM_BACKEND=nvidia-drm, __GLX_VENDOR_LIBRARY_NAME=nvidia, G-Sync / VRR variables), kernel params (nvidia-drm.modeset=1, nvidia_drm.fbdev=1), and powerManagement.enable = true. Channel controlled by nvidiaChannel.

Additional Drives

modules/hardware/drives/ automatically mounts extra internal/external drives. Edit for your specific partition layout.

Gaming

Toggle the entire gaming module with one boolean:

nix
games = true;  # enables Steam, Lutris, MangoHud, gamescope, gamemode…

This enables:

  • Steam + proton-ge-bin extra compat, gamescope session (--rt --expose-wayland)
  • Lutris, Heroic, stable.Bottles — game launchers
  • gamescope + gamemode — compositor/optimization daemon
  • wineWow64Packages.staging, steam-run
  • MangoHud — hidden by default (Shift_R+F12 to toggle), FPS limit cycles with Shift_R+F1 (60 / unlimited / 144 / 165 / 240), disabled in MPV

Architecture

Module-per-feature pattern. Home-manager config is colocated with the NixOS module that owns the feature via home-manager.sharedModules.

text
flake.nix
  └─ mkHost "Default" / "vega"
       └─ hosts/<HOST>/configuration.nix
            ├─ hardware-configuration.nix  (machine-specific)
            ├─ host-packages.nix           (machine-specific packages)
            ├─ modules/scripts/            (helper scripts)
            ├─ modules/core/*.nix          (system foundations)
            ├─ modules/hardware/video/<driver>.nix
            ├─ modules/desktop/<de>/       (from variables)
            ├─ modules/programs/*/         (from variables)
            └─ modules/core/users.nix
                 └─ home-manager (sharedModules pattern)
                      └─ each module injects its own home config

Key decisions:

  • No separate home.nix — all home-manager config lives alongside the NixOS module that owns it
  • Variables as eval-time imports — inherit (import ../../hosts/${host}/variables.nix) ...; drives all module selection
  • Hyprland Lua config — variables.lua is generated at build time by Nix string interpolation; config files are symlinked via xdg.configFile
  • Wallpaper thumbnails built by Nix — pkgs.runCommand + ImageMagick generates 320×180 thumbnails at build time for the rofi wallpaper picker
  • Overlays: additions (custom pkgs like pokego, sddm-astronaut) + modifications (pkgs.stable from nixpkgs-stable)
  • Dev shells are standalone flakes — each has its own flake.lock (gitignored), reachable as flake.templates

FAQ

How do I add a package system-wide?
Add it to hosts/<HOST>/host-packages.nix for one machine, or modules/core/packages.nix for all hosts. Then rebuild.
How do I switch desktop environments?

Edit desktop in variables.nix:

nix
desktop = "gnome";  # hyprland | gnome | plasma6 | i3
Then run rebuild or press Super+U.
How do I change my GPU driver?
nix
videoDriver = "nvidia";       # nvidia | amdgpu | intel
nvidiaChannel = "stable";     # stable | latest | beta | legacy_xxx
How do I enable gaming?
Set games = true; in variables.nix. This enables Steam, Lutris, Heroic, Bottles, MangoHud, gamescope, and gamemode.
How do I use the dev shell templates?
bash
# shell alias (creates dir + direnv allow)
$ fnew rust myproject

# or manually
$ nix flake new -t ~/NixOS#rust myproject
$ cd myproject && nix develop
Where are all keybindings?
Press Super+? or Super+Ctrl+K in Hyprland to open the yad keybindings help menu. Or see the Keybindings page.
How do I change the login screen theme?
nix
sddmTheme = "black_hole";
# astronaut | black_hole | purple_leaves | jake_the_dog | hyprland_kath
How do I set up LUKS encryption?
When installing from the live ISO (./install.sh), the installer asks whether to enable LUKS for the root partition (and optionally the home partition). It walks through password setup, cryptsetup luksFormat, and luksOpen before mounting. If using the same password for both root and home, there's a prompt to confirm.
